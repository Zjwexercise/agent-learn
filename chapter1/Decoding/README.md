# 📖 学习总结：大语言模型解码策略（Decoding Strategies）

---

## 一、什么是 Decoding（解码）？
大模型生成文本是**逐词接龙（Next Token Prediction）**：
根据上文给全词表中每个 Token（如 GPT-2 的 50,257 个词）打分，由**解码策略（Decoding Strategy）**决定挑选哪一个词；拼入上下文后继续预测下一个词，直到触发终止符。

---

## 二、两大核心算法对比

```
1. 贪婪搜索 (Greedy Search)
   [输入] ──> 只选眼前的第 1 名 ──> 只选第 1 名 ──> ... ──> 结束
   特点：速度快、开销小；但目光短浅，若某步选错无法回头修正。

2. 束搜索 (Beam Search)
   [输入] ┬──> 候选路线 1 ──> 评估衍生分支 ──┐
          ├──> 候选路线 2 ──> 评估衍生分支 ──┼──> 综合长远表现，挑选全局总分最高路径
          └──> 候选路线 N ──> 评估衍生分支 ──┘
   特点：同时保留 N 条最有希望的分支路径（平行宇宙），具备前瞻性，防止错过全局最优。
```

---

## 三、束搜索四大核心参数速查表

| 参数名 | 对应代码 | 作用解释 |
| :--- | :--- | :--- |
| **生成步数** | `number_steps` | 树的深度（往后走几步/生成几个词，走满即停）。 |
| **束宽 (Beams)** | `number_beams` | 同时保留的候选路径数量（侦察兵队伍大小）。 |
| **长度惩罚** | `length_penalty` | 长短句倾向天平（`>1.0` 偏爱长句，`<1.0` 偏爱短句）。 |
| **返回序列数** | `num_return_sequences` | 搜索完成后，展示排名前几名的完整句子（必须 $\le$ beams）。 |

## 四、核心学习领悟

### 1. 基座模型的“复读陷阱”
* **现象**：在 `test2` 中输入 `"The Capital of France is"`，模型续写出 `"the capital of France"`（复读主语）。
* **原因**：底层为未经指令微调的原始 **`gpt2`**（124M），没有问答意识，把输入当作纯文本续写，从而掉入 `"is the capital of France"` 这一超高频固定搭配的概率陷阱。
* **领悟**：束搜索在未对齐的小模型上，容易过度追求局部常见搭配而陷入死板循环。

### 2. Token 的广义本质
* **现象**：在 `test3` 中，模型遇到完整句子后，第一步候选词全部为标点（`.`, `!`, `,`），后续还输出了换行符 `\n\n` 和终止符 `<|endoftext|>`。
* **领悟**：Token 并不等于人类理解的英语单词，它包含了**单词、标点、排版符以及控制指令**。语义完整后，标点与结束符的概率会占据绝对优势。
