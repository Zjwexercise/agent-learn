# DummyAgent 踩坑备忘：为什么换模型后刹车失灵了？

## 1. 遇到的怪现象
跑 `DummyAgentLibrary.py` 的阶段 2 时，明明设了 `stop=["Observation:"]`，智谱 GLM-4 却根本没停住，还吐出两行怪东西：
- JSON 前面莫名其妙多了个 `$`（变成了 `${...}`）；
- 直接跳过 `Observation:`，一路抢跑输出了 `Final Answer: ... [insert weather details]` 这种假答案。

## 2. 原因：提示词太原始 + 模型水土不服
这事不能单怪模型或者单怪提示词，是两边碰在一起翻了车：
* **提示词本身太脆弱**：
  模版里写的是 `$JSON_BLOB`，小模型容易看花眼抄成 `${`。更致命的是，我们把刹车点设在 `Observation:`，结果模型直接把这行吞了没打出来，导致刹车直接被绕过去，完全失效。
* **模型生态和体量差异**：
  Hugging Face 官方用的是 70B 的大模型，训练时天天见这种英文 ReAct 模板，知道老老实实在哪里刹车。而智谱 `glm-4-flash` 是轻量中文模型，对这种老式纯英文手搓格式不熟，加上没有真实数据，一着急就直接按试卷格式把后面的占位符也一股脑填满了。

## 3. 启示
靠自然语言提示词去硬卡格式（比如指望模型老老实实打出某个单词来当停用词），极其脆弱，换个模型就崩。这就是为什么后面的 `smolagents` 彻底摒弃了这种做法，要么改用标准工具接口（ToolCalling），要么直接让模型写 Python 代码（CodeAgent）。
